# 📚 Tools & Manuals
Здесь собраны конспекты, примеры конфигураций, шпаргалки и практические руководства, которые я создавал в процессе изучения и работы.

## Цель репозитория

Систематизировать знания и иметь под рукой быстрый доступ к проверенной информации по:
- Контейнеризации и оркестрации (Docker, Kubernetes)
- Базам данных (PostgreSQL, Redis, MongoDB)
- Брокерам сообщений (RabbitMQ)
- Сетевым технологиям и Linux-администрированию
- CI/CD и автоматизации
- И многим другим темам

## 📖 Интерактивная документация

Этот репозиторий собран так, чтобы вы могли просматривать документацию **в виде удобного сайта**.

### 🐳 Запуск через Docker

```bash
# Запустить в фоновом режиме
docker-compose up -d
```

**После запуска сайт будет доступен по адресу: `http://localhost:80`**

### 📄 Что делает Dockerfile
Dockerfile использует образ deloo/markdown-docs для генерации статического сайта из Markdown-файлов:

1. Копирует все файлы в контейнер
2. Переименовывает README.MD в index.md для корректной работы навигации
3. Генерирует HTML-документацию с помощью makedocs
3. Отдает готовый сайт через Nginx

## 🛠 Сборка вручную
```bash
docker build -t tools-and-manuals .docker run -p 80:80 tools-and-manuals
```
