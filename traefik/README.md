`--providers.docker.network=proxynet`
Параметр говорит Traefik'у: «когда определяешь IP-адрес контейнера - смотри именно в сеть proxynet».
Это нужно потому что контейнер может быть подключён к нескольким сетям одновременно, и у него будет несколько IP. Без этого параметра Traefik может взять «не тот» IP.
