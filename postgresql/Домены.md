## Пользовательские типы данных 

**Домен** - пользовательские типы данных с ограничениями

**Составной тип** - тип, объединяющий логически взаимосвязанные данные без создания полноценной таблицы

**Перечисление** - позволяет эмулировать пройстейшие справочные таблицы


### Домены

```sql
CREATE DOMAIN domain_name AS data_type CONSTRAINTS;
```
Например

```sql
CREATE DOMAIN text_no_space_null AS TEXT NOT NULLL CHECK(value !~'\s'); -- Текст без пробелов
```

Мы можем изменять домены при помощи ALTER DOMAIN.

Например:
```sql
ALTER DOMAIN domain_name ADD CONSTRAINT new_constraint [NOT VALID]
```

 **Без NOT VALID:**
 - PostgreSQL проверит ВСЕ существующие значения в столбцах этого типа на соответствие новому ограничению
 - Если найдётся хотя бы одно несоответствие - команда завершится ошибкой

**С NOT VALID:**

 - Ограничение добавляется, но НЕ проверяется для существующих данных
 - Проверяться будут только НОВЫЕ записи или при обновлении существующих
 - Позволяет добавить ограничение, даже если текущие данные ему не соответствуют


Команда, указанная ниже, проверяет, удовлетворяют ли существующие данные в домене указанному ограничению, которое было ранее добавлено с параметром NOT VALID.
```sql
ALTER DOMAIN domain_name VALIDATE CONSTRAINT new_constraint
```
 - PostgreSQL проверяет ВСЕ существующие значения в столбцах, использующих этот домен
 - Если все значения удовлетворяют ограничению, оно помечается как "валидное"
 - Если находятся несоответствия - команда завершается ошибкой

*Пример*
```sql
CREATE DOMAIN text_no_space_null AS TEXT NOT NULL CHECK(value ~ '^(?!\s*$)');

CREATE TABLE agent (
    first_name text_no_space_null,
    last_name text_no_space_null
);

INSERT INTO agent
VALUES ('bob', 'taylor'); -- VALIDE

INSERT INTO agent
VALUES (NULL, 'taylor'); -- NOT VALIDE

INSERT INTO agent
VALUES ('', 'taylor'); -- NOT VALIDE

INSERT INTO agent
VALUES ('   ', 'taylor'); -- NOT VALIDE

INSERT INTO agent
VALUES ('bob junior', 'taylor'); -- VALIDE

-- drop table if exists agent;
-- drop domain if exists text_no_space_null;

 -- Добавляем ограничение длины 32 символа без проверки существующих данных
ALTER DOMAIN text_no_space_null 
ADD CONSTRAINT text_no_space_null_length32 CHECK (length(value) <= 32) NOT VALID;

-- Проверяем существующие данные на соответствие новому ограничению
ALTER DOMAIN text_no_space_null VALIDATE CONSTRAINT text_no_space_null_length32;

INSERT INTO agent
VALUES ('dlfgkndflskngsfgnlkkljfdnklnfgfgfgfgfgfdglkngdlfknglklkn', 'taylor'); -- NOT VALIDE

-- Удаляем ограничение длины, если оно больше не нужно
ALTER DOMAIN text_no_space_null DROP CONSTRAINT text_no_space_null_length32;

```
