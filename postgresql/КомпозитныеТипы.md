# Составные типы

**Составной тип** - тип данных, состоящий из нескольких полей имеющих свой тип

- Нельзя задавать ограничения (сonstraint). Поэтому не так часто используются в таблицах
- Зачастую используются для возврата данных из функций
- Чаще всего составной тип не нужен - Как правило, таблица - лучше!

## 2. Создание составного типа

```sql
CREATE TYPE имя_типа AS (
    поле1 тип_данных,
    поле2 тип_данных,
    ...
);
```

## 3. Использование в таблицах

```sql
CREATE TABLE users (
    id      SERIAL PRIMARY KEY,
    name    TEXT,
    addr    address  -- использование составного типа
);
```

## 4. Вставка данных

```sql
-- Способ 1: Использование ROW()
INSERT INTO users (name, addr)
VALUES ('Иван', ROW('Москва', 'Ленина', '101000'));

-- Способ 2: Строковый синтаксис
INSERT INTO users (name, addr)
VALUES ('Петр', '(СПб,Невский,190000)');  
` '(1, 2, "text")' или ROW(1, 2, 'text') `
```

## 5. Удаление пользовательского типа

```sql
DROP IF EXISTS TYPE type_name [CASCADE | RESTRICT]
```

1. **RESTRICT** (по умолчанию)
   - **Поведение**: Отменяет удаление, если есть зависимые объекты
   - **Когда использовать**: Когда нужно гарантировать, что удаление не затронет другие объекты

2. **CASCADE** (необязательный):

   - Автоматически удаляет все зависимые объекты (таблицы, функции, домены и т.д.)
   - Без CASCADE команда завершится ошибкой, если есть зависимости

## 6. Выборка данных

```sql
-- Получение всего составного поля
SELECT addr FROM users;

-- Доступ к отдельным полям
SELECT (addr).city FROM users;
SELECT u.addr.city FROM users u;  -- альтернативный синтаксис
```

## 7. Обновление данных

```sql
-- Обновление полностью
UPDATE math_cals
SET val = ROW(5.0, 4.0)
WHERE math_id = 1;

-- Обновление частично
UPDATE math_cals
SET val.r = 3.0
WHERE math_id = 1;
```

## *Пример №1*

```sql
CREATE TYPE price_bounds AS (
    max_price real,
    min_price real
);

CREATE OR REPLACE FUNCTION get_price_boundaries() RETURNS SETOF price_bounds AS $$
    SELECT MAX(unit_price), MIN (unit_price)
    FROM products
$$ LANGUAGE SQL;
```

**Без составного типа**

```sql
CREATE OR REPLACE FUNCTION get_price_boundaries(out max_price real, out min_price real) RETURNS SETOF record AS $$
    SELECT MAX(unit_price), MIN (unit_price)
    FROM products
$$ LANGUAGE SQL;
```

## *Пример №2*

```sql
sql
-- Создаем пользовательский тип для комплексных чисел
CREATE TYPE complex AS (
    r float8,  -- вещественная часть числа
    i float8   -- мнимая часть числа
);

-- Создаем таблицу для хранения математических расчетов
CREATE TABLE math_cals (
    math_id serial,    -- автоматически увеличивающийся идентификатор
    val complex        -- значение комплексного типа
);

-- Добавляем тестовые данные - два комплексных числа
INSERT INTO math_cals(val)
VALUES 
    (ROW(3.0, 4.0)),  -- число 3 + 4i
    (ROW(2.0, 5.0));   -- число 2 + 5i

-- Выборка всех записей из таблицы
SELECT * FROM math_cals;

-- Выборка только вещественных частей комплексных чисел
SELECT (val).r FROM math_cals;
SELECT (math_cals.val).r FROM math_cals; -- Аналогично
```
