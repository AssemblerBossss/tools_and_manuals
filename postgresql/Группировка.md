# Группировка

## Введение

Помимо базового GROUP BY, существуют расширенные варианты группировки, которые позволяют получать различные уровни агрегации в одном запросе.

## GROUPING SET

`GROUPING SETS` - это конструкция, которая позволяет указать несколько наборов столбцов для группировки в одном запросе.

```sql
SELECT column1, column2, aggregate_function(column3)
FROM table
GROUP BY GROUPING SETS (
    (column1),
    (column1, column2),
    ()
)
```

**Особенности:**

- Возвращает результат группировки для каждого указанного набора столбцов
- Пустые скобки () дают общий итог (аналог GROUP BY без столбцов)
- Порядок столбцов в наборе важен

### Примеры GROUPING SET

#### Группировка только по supplier_id

```sql
SELECT supplier_id, sum(units_in_stock)
FROM products
GROUP BY supplier_id
ORDER BY supplier_id;

 supplier_id | sum 
-------------+-----
           1 |  30
           2 | 133
           3 | 141
           4 |  64
           5 | 108
           6 |  98
           7 | 110
           8 | 113
           9 | 165
          10 |  20
```

#### Группировка по supplier_id и category_id

```sql
SELECT supplier_id, category_id, sum(units_in_stock)
FROM products
GROUP BY supplier_id, category_id
ORDER BY supplier_id;

supplier_id | category_id | sum 
-------------+-------------+-----
           1 |           1 |  17
           1 |           2 |  13
           2 |           2 | 133
           3 |           2 | 126
           3 |           7 |  15
           4 |           8 |  31
           4 |           7 |   4
           4 |           6 |  29
           5 |           4 | 108
```

#### GROUPING SETS объединяет оба варианта

```sql
SELECT supplier_id, category_id, sum(units_in_stock)
FROM products
GROUP BY GROUPING SETS (
    (supplier_id),
    (supplier_id, category_id)
)
ORDER BY supplier_id, category_id NULLS FIRST;

supplier_id | category_id | sum 
-------------+-------------+-----
           1 |             |  30
           1 |           1 |  17
           1 |           2 |  13
           2 |             | 133
           2 |           2 | 133
           3 |             | 141
           3 |           2 | 126
           3 |           7 |  15
           4 |             |  64
           4 |           6 |  29
           4 |           7 |   4
           4 |           8 |  31
           5 |             | 108
```

### Визуализация связи

```python
Запрос 1 (только supplier_id)        \
                                      > GROUPING SETS объединяет → Итоговый результат
Запрос 2 (supplier_id + category_id) /
```

### Ключевые моменты

- GROUPING SETS фактически выполняет оба группирования в одном запросе
- Строки с NULL в category_id - это результаты группировки только по supplier_id
- Строки с конкретными category_id - результаты группировки по паре столбцов
- ORDER BY ... NULLS FIRST помещает итоговые строки (без категории) выше в каждой группе поставщиков

**Такой подход эффективнее, чем делать два отдельных запроса и объединять их через UNION ALL, так как:**

- Данные читаются только один раз
- Оптимизатор может найти лучший план выполнения
- Код более компактный и читаемый

## ROLLUP

`ROLLUP` - это оператор группировки, который автоматически генерирует иерархические итоговые строки, начиная от наиболее детализированного уровня до общего итога. Это сокращенный синтаксис для определенного типа `GROUPING SETS`.

```sql
SELECT column1, column2, aggregate_function(column3)
FROM table
GROUP BY ROLLUP (column1, column2, column3)

-- Эквивалентно:

GROUP BY GROUPING SETS (
    (column1, column2, column3),  -- Полная детализация
    (column1, column2),           -- Промежуточный уровень
    (column1),                    -- Высший уровень
    ()                            -- Общий итог
)
```

### Примеры ROLLUP

#### Простая агрегация по поставщику

```sql
SELECT supplier_id, sum(units_in_stock)
FROM products 
GROUP BY ROLLUP (supplier_id);

supplier_id | sum  
-------------+------
        null | 3119  ← Общий итог по всем поставщикам
          29 |  130
           4 |   64
          10 |   20
           9 |  165
           7 |  110
          15 |  164
           6 |   98



```

#### Иерархическая агрегация по поставщику и категории

```sql
SELECT supplier_id, category_id sum(units_in_stock)
FROM products 
GROUP BY ROLLUP (supplier_id, category_id)
ORDER BY supplier_id, category_id NULLS FIRST;

supplier_id | category_id | sum  
-------------+-------------+------
           1 |             |   30   ← Итог по поставщику 1
           1 |           1 |   17   ← Детализация по категориям
           1 |           2 |   13
           2 |             |  133   ← Итог по поставщику 2
           2 |           2 |  133
           3 |             |  141   ← Итог по поставщику 3
           3 |           2 |  126
           3 |           7 |   15
           4 |             |   64
..................................
             |             | 3119   ← Общий итог по всей таблице

```

### Ключевые моменты

- Строки с NULL в последнем столбце - промежуточные итоги
- Строка со всеми NULL - общий итог
- Порядок столбцов в ROLLUP() определяет уровни иерархии

### Оптимизация запросов

- Для больших таблиц добавляйте фильтрацию в WHERE
- Используйте ORDER BY ... NULLS FIRST для четкой визуализации иерархии

`ROLLUP` особенно полезен для:

- Финансовых отчетов с промежуточными итогами
- Иерархических структур (регион → город → магазин)
- Анализа продаж с разными уровнями детализации

## CUBE

`CUBE` - это оператор группировки, который генерирует все возможные комбинации агрегации для указанных столбцов. В отличие от ROLLUP, который создает иерархию, CUBE дает полный набор комбинаций.

```sql
SELECT column1, column2, aggregate_function(column3)
FROM table
GROUP BY CUBE (column1, column2)

-- Эквивалентная запись с GROUPING SETS:

GROUP BY GROUPING SETS (
    (column1, column2),  -- Детализированная группировка
    (column1),           -- Группировка по первому столбцу
    (column2),           -- Группировка по второму столбцу
    ()                   -- Общий итог
)
```

### Ключевые особенности

- Все комбинации — создает агрегаты для всех возможных сочетаний столбцов
- Порядок столбцов не важен — результат не зависит от порядка
