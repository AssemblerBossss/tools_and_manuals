# `DENSE_RANK()`
Присваивает ранг каждой строке в рамках секции. В отличие от `RANK()`, он **не делает пропусков** в нумерации при наличии одинаковых значений.

Если у двух строк одинаковое значение, они получают одинаковый ранг, а следующая строка получает следующий по порядку номер (без разрыва).

**Пример**
```sql
SELECT
    employee_id,
    department_id,
    salary,
    DENSE_RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dense_rank_sal
FROM employees;
```

| Задача                    | Как решается через `DENSE_RANK()` |
|---------------------------|-----------------------------------------------------------------------------------------------------------------|
| Топ-N без пропусков       | Найти топ-3 самых высоких зарплаты в каждом отделе, даже если есть ничьи                                        |
| Группировка по диапазонам | Присвоить категорию (например, "Высокий", "Средний") на основе позиции в рейтинге                               |
| Анализ лидербордов        | В играх или соревнованиях, где участники с одинаковым счетом делят место, но следующее место идет сразу за ними |
| Поиск уникальных значений | Отфильтровать только первые вхождения (`WHERE dense_rank = 1`) |

## ⚙️ Важные нюансы
- `ORDER BY` обязателен внутри `OVER()`. Без него ранжирование не имеет смысла.
- `PARTITION BY` сбрасывает счетчик ранга для каждой новой группы.
- Отличие от `RANK()`:
  - `RANK()`: 1, 1, 3 (пропуск номера 2)
  - `DENSE_RANK()`: 1, 1, 2 (нет пропуска)
- Отличие от `ROW_NUMBER()`:
  - `ROW_NUMBER()`: 1, 2, 3 (всегда уникальные номера, даже при равных значениях)
