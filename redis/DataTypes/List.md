# List

**List** - простой список строк отсортированный по порядку вставки данных.

## Особенности

- Максимальная длина списка 2^32 - 1 элементов
- Может хранить изображения (Base64)
- Подходит для сохранения сериализованных JS, Ruby и др. объектов
- Подходит для сохранения констант

### Базовые операции

- `LPUSH <key> <value>` — добавить элемент в начало

- `RPUSH <key> <value>` — добавить элемент в конец

- `LPOP <key>` — удалить и получить первый элемент

- `RPOP <key>` — удалить и получить последний элемент

- `LLEN <key>` — получить длину списка

### Операции с условиями

- `LPUSHX <key> <value>` — добавить в начало, только если список существует

- `RPUSHX <key> <value>` — добавить в конец, только если список существует

### Работа с элементами

- `LINDEX <key> <index>` — получить элемент по индексу

- `LSET <key> <index> <value>` — установить значение по индексу

- `LINSERT <key> [BEFORE|AFTER <pivot> <value>` — вставить элемент относительно другого

### Диапазоны и удаление

- `LRANGE <key> <start> <stop>` — получить диапазон элементов

- `LREM <key> <count> <value>` — удалить элементы по значению

- `LTRIM <key> <start> <stop>` — обрезать список до диапазона

### Блокирующие операции:

- `BLPOP <key> <timeout>` — ждать и получить первый элемент (с таймаутом)

- `BRPOP <key> <timeout>` — ждать и получить последний элемент (с таймаутом)

**Как работают:**

- Если список не пустой — сразу возвращают элемент
- Если список пустой — клиент блокируется до:
  1. Появления элемента в списке
  2. Истечения таймаута

**Особенности:**

- `timeout = 0` — ждать бесконечно
- Можно указывать несколько ключей: BLPOP queue1 queue2 10
- Атомарность — гарантированная обработка конкурентных запросов
- Подходит для очередей задач и worker'ов

### Атомарные перемещения

- `RPOPLPUSH <source> <destination>` — переместить элемент из конца в начало другого списка

- `BRPOPLPUSH <source> <destination> <timeout>` — блокирующая версия RPOPLPUSH
