# Set

**Set** — не сортированный список строк который содержит только уникальные элементы.

## ОСОБЕННОСТИ

- Максимальная длина сета 2^32 - 1 уникальных элементов
- Может хранить список изображений (Base64)
- Подходит для сохранения сериализованных JS, Ruby и др. объектов
- Все операции O(1).

## Команды

### Базовые операции

- `sadd <key> <member>` — добавить элемент в множество
- `srem <key> <member>` — удалить элемент из множества
- `sismember <key> <member>` — проверить наличие элемента
- `scard <key>` — получить количество элементов
- `smembers <key>` — получить все элементы множества
- `spop <key>` — удалить и вернуть случайный элемент
- `srandmember <key>` — получить случайный элемент без удаления

### Операции с перемещением

- `smove <source> <destination> <member>` — переместить элемент между множествами

### Множественные операции

- `sinter <key1> <key2>` — пересечение множеств (общие элементы)
- `sunion <key1> <key2>` — объединение множеств (все элементы)
- `sdiﬀ <key1> <key2>` — разность множеств (элементы только в первом)

### Операции с сохранением результата

- `sinterstore <destination> <key1> <key2>` — сохранить пересечение в новое множество
- `sunionstore <destination> <key1> <key2>` — сохранить объединение в новое множество
- `sdiﬀstore <destination> <key1> <key2>` — сохранить разность в новое множество

### Итерация

- `sscan <key> <cursor>` — итерация по элементам множества
