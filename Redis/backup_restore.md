# Backup and Restore

## Команды для ручного бэкапа

### 1. SAVE — Синхронное сохранение

```bash
127.0.0.1:6379> SAVE
OK
```

**Что делает:**

- Блокирует Redis полностью на время сохранения
- Создает файл дампа (по умолчанию dump.rdb)
- Гарантирует консистентность данных

**Когда использовать:**

- Когда можно позволить простои (ночью или в maintenance window)
- Для небольших баз данных
- Когда нужна 100% гарантия сохранности данных

### 2. BGSAVE — Асинхронное сохранение (Background Save)

```bash
127.0.0.1:6379> BGSAVE
Background saving started
```

**Что делает:**

- Работает в фоновом режиме (не блокирует Redis)
- Создает дочерний процесс для сохранения
- Клиенты продолжают работать без interruption

**Когда использовать:**

- В рабочее время без простоев
- Для больших баз данных
- В 99% случаев — это предпочтительный способ

🔍 Проверка статуса бэкапа:

```bash
# Проверить статус последнего BGSAVE
127.0.0.1:6379> INFO persistence
# Ищите секцию:
# rdb_last_bgsave_status:ok
# rdb_last_save_time:1645534921

# Или проверить историю команд
127.0.0.1:6379> LASTSAVE
(integer) 1645534921
```

### 📁 Где сохраняются бэкапы

По умолчанию файл сохраняется в:

```bash
/var/lib/redis/dump.rdb
```

Настройки пути в redis.conf:

```ini
dir /var/lib/redis
dbfilename dump.rdb
```

После бэкапа:

```bash
# Проверить создание файла
ls -la /var/lib/redis/dump.rdb

# Проверить целостность
redis-check-rdb /var/lib/redis/dump.rdb
```

`CONFIG GET dir` - для получения текущей рабочей директории, где хранятся файлы данных (включая RDB-бэкапы).

```bash
127.0.0.1:6379> CONFIG GET dir
1) "dir"
2) "/var/lib/redis"
```

**Хранится в этой директории:**

- dump.rdb файл бэкапа (RDB)
- appendonly.aof - файл логов (если включен AOF)

### Автоперезапись AOF

```ini
auto-aof-rewrite-percentage 100
```

> Запускает перезапись когда размер AOF файла увеличился на 100% относительно размера при последней перезаписи

Пример: Если после последней перезаписи файл был 64MB → перезапись запустится при 128MB

### 📏 Минимальный размер для перезаписи
```ini
auto-aof-rewrite-min-size 2mb
```

- Минимальный размер AOF файла для возможности автоперезаписи
- Защита от частых перезапис маленьких файлов
- Даже при достижении percentage перезапись не начнется пока файл меньше 2MB
