# String

- Может хранить 512Mb информации
- Может хранить изображения (Base64)
- Подходит для сохранения сериализованных JS, Ruby и др. объектов

## Команды

**Основные:**

`SET <key> <value>` — записать значение

`GET <key>` — прочитать значение

`DEL <key>` — удалить ключ

**Атомарные операции с числами:**

`INCR <key>` +1 (счётчик)

`DECR <key>` -1

`INCRBY <key> <N>` +N

`DECRBY <key> <N>` -N

`INCRBYFLOAT <key> <1.5>` +1.5 (дробные)

**Условные операции:**

`SETNX <key> <value>` — записать только если ключа нет

`MSETNX <k1> <v1> <k2> <v2>` — записать несколько только если всех нет

**Работа с битами:**

`SETBIT <key> <offset> <0/1>` — установить бит

`GETBIT <key> <offset>` — прочитать бит

`BITCOUNT <key>` — посчитать кол-во 1

`BITPOS <key> <0/1>` — найти позицию бита

`BITFIELD <key> <offset> <0/1>` — сложные битовые операции

**Работа с частями строки:**

`APPEND <key> <value>` — добавить в конец

`GETRANGE <key> <start> <end>` — получить подстроку

`SETRANGE <key> <offset> <value>` — заменить часть

`STRLEN <key>` — длина строки

**Групповые операции:**

`MSET <k1> <v1> <k2> <v2>` — записать несколько

`MGET <k1> <k2>` — прочитать несколько

**TTL + значение:**

`SETEX <key> <seconds> <value>` — значение с временем жизни

`PSETEX <key> <ms> <value>` — TTL в миллисекундах

**Специальные:**

`GETSET <key> <new_value>` — получить старое значение и записать новое

`BITOP <key> <AND/OR/XOR>` — битовые операции между ключами
